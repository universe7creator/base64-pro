## Özellikler

### Core Features
1. **Text Encode/Decode**
   - Base64 encode (text → base64)
   - Base64 decode (base64 → text)
   - URL-safe Base64 option
   - Real-time conversion (type-as-you-convert)

2. **File Support**
   - Drag & drop file upload
   - Encode file to Base64 string
   - Decode Base64 to file download
   - Preview image files before/after
   - Support: images, PDF, text files, binary

3. **Advanced Options**
   - Line wrapping (64/76 chars)
   - Padding toggle (=)
   - Charset selection (UTF-8, ASCII, etc.)
   - Copy to clipboard with one click
   - Download as .txt or .b64 file

4. **Bulk Operations**
   - Batch encode multiple files
   - Bulk decode from text list
